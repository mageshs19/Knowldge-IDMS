## 2. Business purpose and flow

The visible job reads 40-byte issue records from EMISSIONS-I and writes 90-byte security records to EFFEKT-O. It derives the as-of date from a parameter or current date, mapping two-digit years below 80 to 20xx and the rest to 19xx (source 164–177; target 266–279). For each input it calls VM9BC50T QUERY001 with key selector2. The returned issue key identifies an owner; the returned currency is used in the output. The program traverses that owner's securities and each security's events.

For each security, SW-168 starts at0. It becomes1 only for event code **0168**, embedded operation **91**, an event date strictly before the cutoff, and an event date at least maturity minus one month. January rolls to December of the prior year; the day is retained without calendar clamping (source 282–298; target 404–419).

A separate reduction selects CI. A 0060 event at or after the cutoff is ignored. The first earlier 0060 sets marker1 and its CI. A 0092 event can replace that choice when its embedded transfer date exceeds the current marker and remains strictly below the cutoff. Equal transfer dates keep the first encountered candidate. The chosen CI and redemption flag are independent: a qualifying redemption without a usable creation/transfer can produce CI 000000 (source 263–315; target 350–447).

After all events, SW-168=1 emits one output row. Target adds read/security/output display counters, initializes the output group per security and removes LAATSTE-OPD, which the complete legacy main only assigns/resets and never reads. It retains the material predicates after date/key conversion; representation, order and service validity remain conditions on equivalence.
