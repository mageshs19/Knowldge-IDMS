# Program enhancement addenda

Create an addendum here only when the existing copied Phase-1 report needs material additional analysis, correction, conflict clarification, or a missing production concept.

Do not edit the copied report in `../programs/`.

Name: `<program>__ADDENDUM.md`.

Every addendum must cite the original report section/line and state whether it adds evidence, corrects an analysis conclusion, or records an unresolved conflict.
