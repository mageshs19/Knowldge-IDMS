> Per-program knowledge base. Rule IDs refer to `../../generic/` and earlier program reports. **NEW** marks a rule first seen here (provisional ID `<CAT>-Z570-n`).

**BZ-family notes [OBS]:** unlike VM1BZ015/130/140 (VMBZMEPI 128 bytes, no called modules, seq step 10), VM1BZ570 reads **VMBD205I** (1200 bytes) and calls VM9BD05T, VM9BC50T, GEDMI03H, GE9RLEU1 and ESENVIRO. Its seq steps by 100 with inserted lines. It has no FFRECAB and uses PARM `DATE8-LS` unconditionally (DATE-IND ignored, L292, L310-L313). The explicit BINDs (L341-L343) match the BZ family. It behaves like a VM1BD590-class validation caller that also walks a BZ LR path, so the VM1BZ prefix does not imply one template.

## 10. LR semantics (VMBTS09.txt L152-L163)

Path `OB-VMBCOUP-VMBEVCP` = `OBTAIN FIRST VMBCOUP WHERE CALCKEY` (0326 → **VMBCOUP-NOT-FND**) → `IF VMBCOUP-VMBEVCP IS EMPTY` (0000 → **NO-VMBEVCP-FND**) → `OBTAIN EACH VMBEVCP WITHIN set` (0307 → **NO-MORE-VMBEVCP**). Statuses tested by the program but **absent from the path**: `NO-VMBCOUP-FND` (L615, L726, L883). Status `NO-MORE-VMBEVCP` after FIRST (L616) is unreachable, because EMPTY returns earlier [INF].

### 15.2 New rules

| Rule | Statement | Guide |
|---|---|---|
| **CUR-Z570-1** **NEW** | Cursor state must mirror LR currency: keep a WS open-flag, set it in OPEN and reset it in CLOSE, and make the CLOSE paragraph conditional on it. Every program-driven loop exit (a switch such as SW-EINDE-COUPON set inside the body, e.g. VERIF-CP-RECYC) must CLOSE. Gate: for every OPEN, list all exit paths and prove exactly one CLOSE. | 04 |
| **CUR-Z570-2** **NEW** | An EOC switch that drives `PERFORM UNTIL <flag>` must be reset inside the OPEN paragraph (not only at program init). Gate: grep `UNTIL <flag>` and check for `MOVE 0 TO <flag>` in 2100-OPEN. | 04 |
| **KEY-Z570-1** **NEW** | When owner and member DCLGENs both carry the LR key, compute the key once (WS helper) and move it to **all** host structures immediately before each SQL. Key arithmetic (`SUBTRACT 1` on rank, CT1/CT2 increments) must hit every structure, and COUNT / SELECT / cursor of one LR request must use the same host set. | 04 |
| **LRO-Z570-1** **NEW** | Validate every `LR-STATUS` literal against the path definition (Schema\VMBTS0n.txt). Literals not returned by the path are dead WHENs. Undefined-in-program real statuses (e.g. NO-VMBEVCP-FND) take the legacy `WHEN OTHER` action (abend here), and DB2 must reproduce that action, not the misleading WHEN list. | 04 |
| **CALL-Z570-1** **NEW** | Keep legacy dynamic calls through data-names (`CALL USERABEN` with `VALUE 'USERABEN'`). Never introduce `CALL 'literal'`. | 03 |
