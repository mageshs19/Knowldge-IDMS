# IDMS Programs/VM4BD230.cbl — IDMS → DB2 Migration Analysis

> Per-program knowledge base. Rule IDs refer to `../../generic/` and earlier program reports; **NEW** marks a rule first seen here (provisional ID `<CAT>-V4230-n`).
>
> - Evidence labels: [OBS] observed, [INF] inferred, [UNK] unknown.
> - Legacy references `Lnnn` = **physical file lines** (verified by search). L1 is `CBL NOSQL` without a sequence number, and the sequence steps vary, so `seq/100 + 1` does **not** give the line. Always use the cited L numbers.
> - DB2 references = `seq NNNNNN` from cols 1-6 of VMDZ4230 (mixed suffixes 00/03/04).
> - The pair is confirmed by VMDZ4230 seq 005203 "2026/04 VM4BD230 -> VMDZ4230".
>
> This is the first VM4 program in the processing order. The VM4BD300 report was written in parallel (direct-DML area sweep). Closest DB2 template: **VMDZ7240 / VMDZ7245**, which have the same READ-FORM INITIALIZE pattern.

## 2. Business flow

```
MAIN  : PROCEDURE DIVISION USING PARAM-ZONEDO; PERFORM D-PROG; TRAIT-FORM UNTIL EOF-FORM;
        F-PROG; GOBACK                                                                   [L1525-1530]
D-PROG: DATE-IND='0' → ACCEPT DATE-YMD FROM DATE, MOVE CORR → DATE-DMY8, >60 → 19 else 20
        else DATE8-LS → DATE-DMY8, MOVE CORR → DATE-YMD                                  [L1533-1544]
        MOVE CORR → DATE-YMD8 (never read) ; → DATE-DSMSY → HFD1-DATE                    [L1545-1548]
        OPEN INPUT FORM, OUTPUT LISTE ; PERFORM IMP-ENTETE (legend pages + IMP-TITRE)    [L1550-1553]
        IF NOT EOF → READ-FORM ; IF EOF → WRITE NIHIL-NEANT AFTER 2                      [L1555-1560]
TRAIT : ADD 1 TO WS-TEL-REC (never shown)                                                [L1563]
        CT-OPD OF VMBFORM: 41/43 IMP-VMBFRV | 51/52 IMP-VMBFAS | 61 IMP-VMBFDN | 65 IMP-VMBFRT
        | 71 IMP-VMBFTE | 81/82 IMP-VMBFR | 91/92/90/94 IMP-VMBFAR ; each + IMP-ORDER    [L1565-1591]
        other → DISPLAY '##&&VM4BD230 - STOP02' / '*** ONBEKEND RECORDTYPE ***' / CT-OPD;
                CALL USERABEN                                                            [L1593-1596]
        PERFORM READ-FORM                                                                [L1598]
READ  : READ FORM INTO FORM-IN AT END 'Y' → FIN-FORM                                      [L1608]
        not EOF: FORM-IN → VMBFAS, VMBFAR ; PART1 → VMBFORM ; PART2 → VMBFDN, VMBFRT,
                 VMBFRV, VMBFR ; PART2-TE → VMBFTE ; PART2-TEL → VMBFTEL (group MOVEs)    [L1609-1619]
IMP-x : IF CTRL > limit → IMP-TITRE ; build CIDI + detail lines ; WRITE ; ADD n TO CTRL  [L1626-2214]
ORDER : IF CTRL > 40 → IMP-TITRE ; print the 074SORD order block ; ADD 18 TO CTRL         [L2984-3092]
F-PROG: CLOSE FORM LISTE                                                                 [L1601-1603]
```

DB2 flow: identical, except for the INITIALIZE added before READ (seq 160904-160908) and the renamed literals (§11) [OBS diff].

### 15.2 New rules (provisional)

| ID | Rule |
|---|---|
| **PLAT-V4230-1 NEW** | If a program has `SCHEMA SECTION` and/or `COPY IDMS <record>` but **zero DML** and no SUBSCHEMA-CTRL: delete IDMS-CONTROL, PROTOCOL, IDMS-RECORDS, SCHEMA SECTION and the DB clause; convert only the record COPYs; add no SQLCA, DCLGEN, COMMIT or restart; keep `CBL NOSQL`. Seen in VM4BD230 and VM4BZ250. |
| **CPY-V4230-1 NEW** | `COPY IDMS [RECORD] <rec>` → `COPY VMDZI<last 3 chars of rec>.` (VMBFORM→VMDZIORM, VMBFR→VMDZIBFR, VMBFTEL→VMDZITEL, VMBFC→VMDZIBFC). Keep the 01-name `<rec>` and all `OF <rec>` qualifiers unchanged. Add the terminating period if it is missing. Name collisions on the last 3 characters must be checked across the dictionary. |
| **NAME-V4230-1 NEW** | Apply NAME-03 to program-name literals split over adjacent FILLER VALUEs (here 'V' + 'M4BD230' → 'V' + 'MDZ4230'). Keep the total length unchanged. |
| **HLP-V4230-1 NEW** | Do not add INITIALIZE before `READ … INTO` or before group MOVEs that fully overwrite their targets (not legacy; Q-25). If a template emits it, the engine must prove it neutral (INTO length = record length) and log it. |
