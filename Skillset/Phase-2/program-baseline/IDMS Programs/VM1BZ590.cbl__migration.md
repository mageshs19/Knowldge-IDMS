## 2. Business flow

```
MAIN (L144-147)   D-PROG ; TRAIT THRU TRAIT-EX UNTIL E-O-F ; F-PROG ; STOP RUN
D-PROG (L149-153) ACCEPT-DATE ; OPEN-FICHIER (OPEN, BINDS, READY ×2 UPDATE) ; TRAIT-FFRECAB ; LECT-FORMC

TRAIT (L155-170)

TRAIT-SUIT (L172-204)
```

## 9. OCCURS / REDEFINES

No OCCURS. ZONEDO REDEFINES (DATE6R-WS / DATE6 / DATE8 / DATEYYMD, DATEYYMD-2M / -2M-9) and PARAM-ZONEDO are byte-identical in DB2 (DATE-04) [OBS]. VMBD205I CT-OP-GDIFC REDEFINES (L167-169) is displayed as a group in the skip message on both sides. `ADD 0 TO CT-OPD` (L272) normalises the packed sign nibble (F → C) of a value MOVEd from unsigned DISPLAY so the CALC hash/byte compare matches the stored key [INF IDMS CALC]; in DB2 the compare is numeric, so the kept `ADD 0` (seq 009000) is harmless and redundant.
