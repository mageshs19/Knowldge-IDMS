# IDMS Programs/VM4BD306.cbl — IDMS to DB2 Migration Analysis

> **Purpose.** Knowledge base for one program pair: legacy VM4BD306 vs the manual DB2 conversion VMDZ4306. Written for a downstream conversion engine and its reviewers.
>
> **Evidence labels:** `[OBS]` observed in source, `[INF]` inferred, `[UNK]` needs a human answer. **NEW** marks a rule first proposed here (provisional ID `<CAT>-V4306-n`).
>
> **Line references:** legacy = **physical file lines** (`L`), verified by a numbered listing. The file has inserted seqs (006410, 007710-007750, 008410, 013410-013540, 013610, 020810, 017310-017392), so seq/100 is **not** the line number after L64 (e.g. seq 019400 `STORE VMBTL07-R01` = L210, seq 021700 `COMMIT` = L234). DB2 = `seq NNNNNN` (cols 1-6 of VMDZ4306). Schema-Listing, VMBTS07, DCLGEN and mapping-CSV refs are physical lines.
>
> **Pairing.** Legacy L4-5 "STOCKAGE DES MUTATIONS / ADAPTATION DU VM4OM190" = VMDZ4306 seq 000900 "STORAGE OF MUTATIONS ADAPTATION OF THE VM4OM190" (exact translation; VM4OM190 occurs in no other VMDZ [OBS grep]). The pair also shares FD IKB DD010 120 bytes, the WS-IN-REC layout, the paragraph names STOCKAGE/LECTURE, and the legacy comments "NA 99 OPERATIES EEN COMMIT" and "LEZEN VAN DE EERSTE TE VERWERKEN RECORD" (seq 021000, 014600). **Confidence: High.**
