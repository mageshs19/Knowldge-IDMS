## 10. LR / DML semantics

No LR request is issued (no `OBTAIN … WHERE`, no LR-STATUS test) [OBS grep]. Path statuses LR-FOUND / LR-NOT-FOUND / LR-ERROR do not apply; Schema\VMBTS07.txt not involved. Direct-DML semantics:

| Legacy construct | IDMS meaning | DB2 |
|---|---|---|
| `FIND CALC VMBFORM` (DUP NOT ALLOWED, L729) | establishes owner currency only; 0326 → 790000 abend | no owner read; owner key used as FK filter on the member table (FK_VMBFORM_M1, CSV L632-637, L768-773) |
| `OBTAIN FIRST <member> WITHIN VMBFORM-M1` | first occurrence **of that record type** in a multi-member set (VMBMESS/FDN/FRT/FR/FTE/FRV share VMBFORM-M1); 0307 → abend | per-table SELECT naturally isolates the type; ORDER BY NR_ID DESC = "FIRST" under ORDER FIRST (ORD-01, Q-17) |
| `OBTAIN NEXT VMBFRV` loop + program filter AM-CNS/NR-ST (L325-341) | first matching member | not converted (dropped); would be LRO-02: SELECT with FK + `AM_CNS = … AND NR_ST = …` ORDER BY set order FETCH FIRST |
| `MODIFY <member>` | update of current record | UPDATE by fetched NR_ID (LRM-01) |
| VMBFTE group skip (L266-285) | one MODIFY per exchange form; following input lines with the same NR-CIO/NR-ID/DA-CREA/CT-OP are consumed without processing | not converted (D-01, **LRS-N625-1**) |
| CALL PROCEDURES INFOCOMP/INFODCOM (L731-734) | compression | ignored (PROC-01) |

### 15.2 New rules

| Rule | Statement | Guide |
|---|---|---|
| **DML-N625-1** | **NEW.** Direct DML `FIND CALC <owner>` (0326 → abend) + `OBTAIN FIRST <member> WITHIN <set>` (0307 → abend) + `MODIFY <member>` → singleton `SELECT <member PK> FROM <member view> WHERE <all owner CALC-key FK cols> ORDER BY <surrogate> <set direction> FETCH FIRST 1 ROW ONLY`, then `UPDATE … WHERE <PK>`. Both not-found statuses collapse into SQLCODE 100; keep the legacy owner/member messages either by an owner probe (LRS-11 style) or by recorded sign-off. | 04 |
| **RST-N625-1** | **NEW.** Inspect legacy restart skip loops for counters incremented in both the read paragraph and the loop body (or never). Record as L-defect, test odd/even checkpoint counts, and apply the template `NB-READ TIMES` positioning (RST-10). | 02 |
| **RST-N625-2** | **NEW.** Legacy end-of-run `ROLLBACK` (with `FINISH` commented) after a conditional final COMMIT is not translated to SQL ROLLBACK: the template always performs the final checkpoint with CO_ID_RS '1'. | 02 |
| **MSG-N625-1** | **NEW.** Never MOVE a DB2 view name into a message field sized for the legacy record name (e.g. WS-RECORD X(7)); keep the legacy record name or widen the field. Grep target for `MOVE '<view>' TO <field>` against the field's PIC. | 03 |
| **LRS-N625-1** | **NEW.** When a decommissioned-record branch is dropped (LRS-09-b), also drop or justify every auxiliary control structure tied to it (switches, previous-key fields, group-skip read loops) and list the input codes that become silent no-ops. | 04 |
