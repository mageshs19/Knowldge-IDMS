```

TRAIT (L142-L159)  J ← RANK + NB-CPSEQ − 1 ; TRAIT-COUPONS VARYING I FROM RANK UNTIL I > J

  else: RECH-EVCP (OBTAIN FIRST, L208) ; RECH-EVCP-NEXT UNTIL SW-OK='1' (L202, L223-L237)
     each: status ≠ LR-FOUND → DISPLAY + USERABEN ; '0060' & 6 GDIFC fields = 0 & cause ∈ list → SW-OK '1'
```

### 15.2 New rules

| Rule | Statement | Guide |
|---|---|---|
| **SCP-Z580-1** **NEW** | Sentence scope is business logic. Every legacy period that closes an IF/ELSE must become a period or END-IF at the same point; statements appended by the template after a legacy IF must follow a closed scope. | **LRO-Z580-1** **NEW** | First-match search loop (`OBTAIN FIRST` + `OBTAIN NEXT UNTIL SW-OK`, abend on NO-MORE) followed by one MODIFY → `SELECT NR_ID … WHERE <all loop predicates> ORDER BY NR_ID <set direction> FETCH FIRST 1 ROW ONLY`; 100 → legacy abend texts + abend; then `UPDATE … WHERE NR_ID`. The ORDER BY direction is the business rule, not a style choice. | 04 |
