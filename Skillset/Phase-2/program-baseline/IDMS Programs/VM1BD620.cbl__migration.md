# IDMS Programs/VM1BD620.cbl — IDMS → DB2 Migration Analysis

> Per-program knowledge base. Rule IDs refer to `../../generic/` and earlier reports; **NEW** marks a rule first seen here (provisional ID `<CAT>-N620-n`).
>
> - Evidence labels: [OBS] observed, [INF] inferred, [UNK] unknown.
> - Legacy references `Lnnn` are **physical file lines** (= seq/100 + 1; verified, e.g. `OBTAIN FIRST` seq 012000 = L121, `CALL USERABEN` seq 024000 = L241). DB2 references are `seq NNNNNN` (cols 1-6 of VMDZ1620).
> - Closest DB2 sister: **VMDZ7240** (same DZBFASC1 cursor, same 700/800/900 template, same STOP-01 layout) → XPG-01 clone. Not a sister of the VM1BD5xx event programs.

## 2. Business flow

```
MAIN   (L90-93)   BEG-PROG ; BEHAND THRU BEHAND-EX UNTIL EOF ; END-PROG ; GOBACK
BEG-PROG (L96-109) DATE-DMY8 ← DATE8-LS (PARM only, DATE-IND ignored) → DATE-YMD8 (CCYYMMDD)
                  READY 2 areas ; OPEN ; BEHAND-FFRECAB (restart) ; READ first
BEHAND (L112-137)
  KY-VMBFAS ← SPACES, 0029, NR-CIO-FORM-AS-R, NR-ID-FORM-AS, DA-CREA-FORM-AS-R, CT-OPG-R, CT-OPD-R
  OBTAIN FIRST VMBTL06-R01 WHERE OB-DUP-VMBFAS                     (L121)
    LR-ERROR / LR-NOT-FOUND            → STOP-01                   (L122-126)
    LR-FOUND → MOGELIJKE-DUBBELS:                                  (L127-130, L201-217)
         IF first CT-SL = 'I': LR-STATUS ← SPACES
            PERFORM VOLGENDE UNTIL NR-ST(VMBFAS) = NR-ST(input) OR 'VMBFAS-NOT-FND'
            VOLGENDE = OBTAIN NEXT … OB-DUP-VMBFAS; LR-ERROR/LR-NOT-FOUND → STOP-01 (L220-228)
    'VMBFAS-NOT-FND' (first call or end of walk) → STOP-01         (L131-134)
  DA-CPTA-FORM-AS ← DATE-YMD8 ; MODIFY VMBTL06-R01 WHERE MODIFY-VMBFAS   (L136-137)
BEHAND-EX (L140-153) ADD 1 TELLER ; >99 → NS-REC-FF-IN += TELLER, MODIFY FFRECAB, COMMIT
END-PROG (L156-162) NS-REC-FF-IN += TELLER ; MODIFY FFRECAB ; FINISH ; CLOSE
STOP-01  (L231-241) 'VM1BD620 : FORMULIER NIET GEVONDEN' + 6 key fields + LR-STATUS ; CALL USERABEN
```

DB2 flow: BEHAND (seq 022800-027404) builds the key in DCLDZBFASTV, OPEN DZBFASC1, `PERFORM 820-FETCH UNTIL EOF OR UPDATE-DONE`, PROCESS-ROW (seq 031004-034304) reproduces the first-row test with `WS-ROW-COUNT = 1`, 840 UPDATE, CLOSE. Equivalent [OBS], see §10.

## 10. LR semantics

| LR request | Path (VMBTS06) | Legacy statuses | DB2 |
|---|---|---|---|
| `OB-DUP-VMBFAS` FIRST / NEXT | `OBTAIN EACH VMBFAS WHERE CALCKEY EQ KY-VMBFAS OF LR`; `ON 0326 RETURN VMBFAS-NOT-FND`; `ON 0000 NEXT` (L281-286) | LR-FOUND = next duplicate; VMBFAS-NOT-FND = none / end of duplicates; LR-NOT-FOUND not producible (no LR WHERE) [INF]; LR-ERROR = other | cursor on full CALC key, ORDER BY NR_ID ASC; 0 = LR-FOUND, 100 = VMBFAS-NOT-FND (fatal), OTHER = LR-ERROR |
| `MODIFY-VMBFAS` | `FIND CURRENT VMBFAS; MODIFY VMBFAS` (L194-199) | currency = matched duplicate | UPDATE by CALC cols + fetched NR_ID (LRM-01; PK of the "current" row) |
| CALL PROCEDURES INFOCOMP/INFODCOM on VMBFAS (Schema-Listing L417-420) | — | — | ignored (PROC-01) |

**Program-side filter equivalence [OBS]:** legacy tests `CT-SL = 'I'` on the **first** duplicate only (L211); the NR-ST test is evaluated before the first VOLGENDE (test-before UNTIL), so the first duplicate itself can match. DB2 PROCESS-ROW: row 1 non-'I' → update row 1; row 1 'I' → update row 1 if NR-ST matches; rows n>1 → update if FIRST-ROW-I and NR-ST matches; CT-SL of rows n>1 ignored in both. Branch-for-branch identical (DSP-02).

Not a LRO-02 single SELECT: the filter depends on the first row's CT-SL, so a cursor with a fetch loop is the right shape → **LRO-N620-1 NEW**.

## 15. Rules and open questions

### 15.1 Reused rules

### 15.2 New rules

| Rule | Statement | Guide |
|---|---|---|
| **LRO-N620-1** | **NEW.** CALC-duplicate walk (`OBTAIN FIRST/NEXT <LR> WHERE OB-DUP-<REC>`, path `OBTAIN EACH <REC> WHERE CALCKEY EQ …`) with a program-side stop condition → cursor `WHERE <all CALC cols> ORDER BY <surrogate> ASC` (DUP LAST; DESC for DUP FIRST) `FOR READ ONLY`, fetch loop `UNTIL EOF OR done`, `<REC>-NOT-FND` → SQLCODE 100 with the legacy NOT-FND action. Conditions the legacy evaluates on the first duplicate only are reproduced with a row counter. Update via searched UPDATE on CALC cols + fetched surrogate. | 04 |
| **ERR-N620-1** | **NEW.** SQLCODE 100 / 0 (business "not found") must never be routed to SQLERROR as the only abend mechanism. Program STOP paragraphs keep their legacy `CALL USERABEN` (via 900-CALL-USERABEN); SQLERROR is for unexpected SQLCODEs only. | 04 |
| **MSG-N620-1** | **NEW.** DISPLAY texts of abend paragraphs stay verbatim (Dutch/French), only the program name is substituted (NAME-03); do not translate or drop status lines — add `SQLCODE` where the legacy showed LR-STATUS. | 03 |
| **PLAT-N620-1** | **NEW.** Keep the legacy termination verb (`GOBACK` stays `GOBACK`). | 04 |
