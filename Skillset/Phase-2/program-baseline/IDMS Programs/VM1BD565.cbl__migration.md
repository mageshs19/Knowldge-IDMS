## 2. Business flow

```
D-PROG : DATE-IND = '0' → system date (window 60) ; else PARM DATE8-LS   [L118-132]
         READY 2 areas ; FFRECAB 'VM1BDF565-A' + DATE-YMD8 (restart)
TRAIT  : STCIRC = '1' → STORE-EVEF  else MOD-EVEF ; checkpoint every 100
STORE-EVEF : EVEF ← date, 0168/1815, NR-ID-GOOD, DB-NR-CI
             (CO-STATE-EVPRAN ← SIGNAAL2 DISABLED 2003 → stays SPACE)
             EFF key → STORE ST-VMBEVEF ; LR-ERROR / NOT-FND → 'ST-VMBEVEF' + status + NR-ST, abend
MOD-EVEF   : first EVEF 0168/1815 under EFF → rebuild GOOD + CI → MODIFY
F-PROG     : CLOSE ; ADD TELLER ; MODIFY FFRECAB ; FINISH (final checkpoint present)
```

## 5. Field trace (differences only)

| Item | Legacy | DB2 | Equal? |
|---|---|---|---|
| **Run date** | DATE-IND='0' → system date, otherwise PARM | Same IF block (seq 020100-021500), **then unconditionally overwritten**: `MOVE DATE8-LS TO DATE-DMY8` + 3 × MOVE CORR (seq 021800-022100) | **NO when DATE-IND = '0' (D-01)** |
| CO-STATE-EVPRAN / CO_STEVPRN | SPACE (MOVE SPACES TO VMBEVEF; SIGNAAL2 move commented) | SPACE (INITIALIZE DCLDZEVEFTV) | yes → **CMT-01 NEW** |
| EVEF FK / NR_IDGOOD / NR_CI | as VM1BD555 | as VMDZ1555 | yes (C-01 cross) |
| EVEF event date | DATE-YMD8 | DA-DD-MM-CCYY recomputed from DATE-YMD8 at the start of 11000 | yes, apart from the D-01 date source |

### D-01 detail

1. DB2 keeps the legacy DATE-IND logic.
2. It then appends the VMDZ1555 template block (PARM-only date) without removing it [OBS seq 021800-022100].
3. Effect with `DATE-IND = '0'`: the system date is discarded. DATE8-LS content is used instead.
   - If the PARM carries only the indicator (DATE8-LS = spaces or garbage), then DA-DD-MM-CCYY becomes non-numeric or invalid.
   - The restart SELECT on DA_CR_RS (a DATE column) then fails (-180 / -181 [INF]) → SQLERROR abend. Or, if a stale date is supplied, events get the **wrong DA_CREVTPD** and the restart key is wrong.
4. With `DATE-IND ≠ '0'` the result is identical to legacy (both use the PARM).
5. The duplicate override is a cloned-template defect shared by **VMDZ1565, VMDZ1575, VMDZ1595 and VMDZ7245** [OBS, corrected by the VM1BD575/595 analyses]. Of the earlier DATE-IND programs checked (1190, 1251, 1255, 1257, 1263, 1510, 1515, 1546) none has it → **XPG-01** (template clone).

## 7. Cursor / transaction design

No cursors. Commit every 100 records plus at F-PROG.

**Restart template variant:** 800-RESTART-CONTROL performs 700-SELECT, which itself dispatches to 810 / 820 inside its EVALUATE (QUERYNO 496). The structure differs from VMDZ1555 but the result is the same [OBS seq 053200-054000].

## 11. Decommissioned fields

**CO-STATE-EVPRAN ← SIGNAAL2** was disabled in 2003 ("BESTAAT NIET MEER NA INTEGRATIE"). DB2 correctly leaves CO_STEVPRN = space and does not re-activate it.

**CMT-01 NEW:** commented-out legacy statements are not business logic. Never resurrect them. Do confirm that the target column gets the same default the legacy `MOVE SPACES` gave.
