## 2. Business flow

```
MAIN (L132-135)        D-PROG ; TRAIT UNTIL E-O-F ; F-PROG ; STOP RUN
D-PROG (L137-143)      ACCEPT-DATE ; OPEN-FICHIER ; TRAIT-FFRECAB ; IF NOT E-O-F → LECT-COUP-PAY
ACCEPT-DATE (L189-200) DATE-IND='0' → ACCEPT DATE6R-WS FROM DATE (YYMMDD) → DATE8 → DATE6
                       else DATE6 ← DATE6-LS (DDMMYY) ; DATEYYMD ← CORR DATE6 ; D-YEAR > 60 → 19 else 20
OPEN-FICHIER (L202-209) OPEN ; PROGRAM-NAME ← 'VM1BZ620' ; BIND ×3 ; READY ×2
TRAIT-FFRECAB (L220-240) key 'VM1BZ620-A' + DATEYYMD + NS-SET 0 ; OBTAIN CALC FFRECAB
                       found → LECT VARYING TELLER 1.. UNTIL E-O-F OR TELLER > NS-REC-FF-IN
                       not found → CT-SET '1', CT-REC 'A', counts 0, NB-DAY 7 ; STORE FFRECAB
                       TELLER ← 0
TRAIT (L145-180)       IF CO-STCIRC-OORD NOT = '9'
                         VMBEFF key ← SPACES, '1002', NR-ST-GDIFC(13), NS-DB-GDIFC(2)
                         OBTAIN FIRST VMBTL07-R01 WHERE OB-VMBEFF
                         'VMBEFF-NOT-FND' → CONTINUE
                         else RANK-DERN ← NS-RANK + NB-CPSEQ − 1
                              IF NX-CPAID OF VMBEFF NOT < RANK-DERN → CONTINUE
                              else NX-CPAID ← RANK-DERN ; MODIFY … MO-VMBEFF
                         TELLER+1 ; TELLER > 99 → NS-REC-FF-IN += TELLER ; FIND CURRENT/MODIFY FFRECAB ; COMMIT ; TELLER 0
                       END-IF ; LECT-COUP-PAY
F-PROG (L182-187)      NS-REC-FF-IN += TELLER ; FIND CURRENT/MODIFY FFRECAB ; FINISH ; CLOSE
```

DB2 flow (seq 008935-010551): identical skeleton. ACCEPT-DATE adds PROGRAM-NAME, 600-GET-TIMESTAMP, EOF switch init and DA-DD-MM-CCYY (seq 010566-010590). D-PROG calls 700-RESTART-CONTROL. 200-TRAIT does `INITIALIZE DCLDZBEFFTV`, same STCIRC IF, key build, 810 SELECT, `EVALUATE SQLCODE` 0/100/OTHER, same COMPUTE and `NOT <`, 820 UPDATE, `IF WS-TELLER > 99 → 900-PROCESS-COMMIT` **inside** the STCIRC IF (as legacy). F-PROG: CLOSE, 2 DISPLAYs, 900-PROCESS-COMMIT (CO_ID_RS '1').
