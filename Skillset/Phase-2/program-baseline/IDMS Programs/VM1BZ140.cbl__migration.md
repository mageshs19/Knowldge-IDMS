```

  ADD 1 TO TELLER                                                          [L165]
  VMBCOUP ← SPACES; key NR-ID-STOCK-CD ← NR-ST-COUPON 9(13), NS-DB, NS-ID-COUPON;

  ELSE STORE … ST-VMBEVCP ; IF CT-OP-COUPON = 99 → AM-INTGR ← AM-IND, MODIFY … MO-VMBCOUP [L210-214]
```
