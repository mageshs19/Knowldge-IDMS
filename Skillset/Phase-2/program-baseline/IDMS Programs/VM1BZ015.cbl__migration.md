# IDMS Programs/VM1BZ015.cbl — IDMS → DB2 Migration Analysis

> Per-program knowledge base. Rule IDs refer to `../../generic/` and earlier reports; **NEW** marks a rule first seen here (provisional ID `<CAT>-N015-n`).
>
> - Evidence labels: [OBS] observed, [INF] inferred, [UNK] unknown.
> - Legacy references `Lnnn` are **physical file lines**. VM1BZ015 sequence numbers step by 10 with gaps (000010 … 002510), so the VM1BD rule `seq/100 + 1` does **not** apply (verified: `OBTAIN FIRST` seq 001899 = L154, `CALL USERABEN` seq 001913 = L165, `OBTAIN NEXT` seq 002092 = L288). DB2 references are `seq NNNNNN` (cols 1-6 of VMDZ1015).
> - Closest DB2 sisters: **VMDZ1573** (same DZCOUPTV/DZEVCPTV pair, COUNT-COUP/COUNT-EVCP, NS-DB-TEMP, reverse date block) and **VMDZ1130 / VMDZ905T** (same author, same FETCH error branch without SQLERROR) → XPG-01.

## 2. Business flow

```
MAIN (L105-109)  1000-BEGIN ; 2000-PROCESS UNTIL EOF-TITRES ; 3000-END
1000 (L112-136)  DATE-IND='0' → ACCEPT DATE else DATE-PARM ; window >80 → 19   (DATE-YMD8 never used: L-02)
                 OPEN I/O ; INITIALIZE WS-KY-COUPON ; READ first ; BIND ; READY AR-VMBCOUP RETRIEVAL
2000 (L138-207)  IF CO-OPG='53' AND NR-ST≠0/LOW AND CO-STCIRC='9'
   [A] KY-COUPON ← NR-ST-FORM-AS(13) + NS-IDCP + NS-DB-STOCK ; WS-KY-COUPON same      (L144-153)
       OBTAIN FIRST VMBTL09-R01 WHERE OB-VMBCOUP-VMBEVCP                            (L154)
       PERFORM P150 UNTIL LR-STATUS ≠ 'LR-FOUND'                                    (L155-156)
       VMBCOUP-NOT-FND → continue ; OTHER (incl. NO-VMBEVCP-FND, L160 commented) → '1-*-' USERABEN (L157-166)
   [B] IF CO-OPD 41/43 AND CO-SEL≠'0' AND NR-STNEW ∉ {0, LOW, NR-ST}                (L168-179)
       same walk with NR-STNEW-OORD, same NS-IDCP/NS-DB ; error marker '3-*-'       (L180-201)
       ([B] runs whatever the outcome of [A] — only an abend stops it)
   READ next                                                                         (L206)
P150 (L224-243)  PERFORM P200 UNTIL ≠ LR-FOUND ; NO-MORE-VMBEVCP → ok ; OTHER → '2-*-' USERABEN
                 ADD 1 TO WS-NS-ID-COUPON ; rebuild key ; OBTAIN FIRST … (next coupon)   (L238-242)
P200 (L245-289)  IF TE-REF-EVPR = TS-CREA-OORD → build VMBZMEPI, WRITE O-FILE (L247-287)
                 OBTAIN NEXT VMBTL09-R01 WHERE OB-VMBCOUP-VMBEVCP                    (L288)
3000 (L209-213)  CLOSE ; FINISH ; STOP RUN
```

DB2 flow: 2000 (seq 023200-034600) builds DCLDZCOUPTV/DCLDZEVCPTV keys, COUNT-COUP + COUNT-EVCP, if both > 0 OPEN/FETCH DZCOUPC1 and `PERFORM P150 UNTIL WS-COUP-END`; P150 (seq 036900-040100) = P200 loop UNTIL EOC, CLOSE, coupon+1, COUNT-COUP only, re-OPEN. The TE-REF test moved into the cursor WHERE (seq 018300). **Block [B] is nested inside the success branch of [A]'s COUNT test (D-01).**

## 10. LR semantics

Path `OB-VMBCOUP-VMBEVCP` (VMBTS09.txt L152-163): `OBTAIN FIRST VMBCOUP WHERE CALCKEY = KY-COUPON OF LR` (0326 → VMBCOUP-NOT-FND) ; `IF VMBCOUP-VMBEVCP IS EMPTY` (0000 → NO-VMBEVCP-FND, 1601 → NEXT) ; `OBTAIN EACH VMBEVCP WITHIN VMBCOUP-VMBEVCP` (0307 → NO-MORE-VMBEVCP).

| Legacy status | Meaning | DB2 |
|---|---|---|
| LR-FOUND | next VMBEVCP of the coupon | FETCH 0 (filtered by TE-REF in SQL) |
| VMBCOUP-NOT-FND | coupon rank missing → end of coupon walk | COUNT-COUP = 0 → WS-COUP-END / skip |
| NO-VMBEVCP-FND | coupon without events → **abend** (commented WHEN L160, L231) | first coupon: COUNT-EVCP = 0 → SQLERROR(0) (D-04); next coupons: not tested (D-03) |
| NO-MORE-VMBEVCP | set exhausted | FETCH 100 → DZCOUPC1-EOC |
| LR-NOT-FOUND | not producible (no LR WHERE clause) [INF] | — |
| LR-ERROR | DML error | SQLERROR in COUNT/OPEN; **not** in FETCH (D-02) |

`OBTAIN NEXT` resumes at the iterative `OBTAIN EACH` [INF LRF semantics]; `OBTAIN FIRST` after ADD 1 restarts the path for the next coupon — DB2 re-OPEN per coupon is the correct equivalent. Program-side filter TE-REF (L247) → cursor WHERE: non-matching events are skipped in both; all matches written (not first-only, so no FETCH FIRST). VMBCOUP/VMBEVCP CALL PROCEDURES INFOCOMP/INFODCOM (Schema-Listing L202-205, L276-279) ignored (PROC-01). Elements VMBSIC/VMBFC/VMBFGDC/VMBJGDC not touched.
