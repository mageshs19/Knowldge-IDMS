> Per-program knowledge base. Rule IDs refer to `../../generic/` and earlier program reports; **NEW** marks a rule first seen here (provisional ID `<CAT>-N590-n`).
>
> - Evidence labels: [OBS] observed, [INF] inferred, [UNK] unknown.
> - Legacy references `Lnnn` = **physical file line numbers** (verified by search). The legacy file has inserted lines without a sequence number (HOMAJ/IELEE 2010), so `seq/100 + 1` is only valid between insertions — do not use it.

## 2. Business flow

```
INIT  : DATE-IND = '0' → ACCEPT DATE, window >60 → 19xx ; else DATE8-LS (DDMMCCYY)     [L246-260]
        CALL ESENVIRO [L262] ; OPEN 1 input + 5 output files [L266-271]
        READ first; AT END → CLOSE all, STOP RUN (no DB call)                          [L273-281]
        VM9BD05T OPEN: NM-FUNCTION 'CONSULTT', EF1-INPUT spaces, DA-PARM ← DATE-YMD8    [L285-295]
        INITIALIZE GEDMI03H-IN, WS-COMP-DATE                                           [L299-300]
LOOP  : HOOFDVERWERKING UNTIL SW-EOF = 'Y'                                             [L305]
  CO-SEVERITE, HULP ← '1'                                                              [L362-363]
  CONTR-110 : issue (product/IRMO/DA-UB) changed vs cache → VM9BC50T; RC≠'0000' → USERABEN   [L392-431]
  CONTR-210 : CIO+DA-CREA vs GEDM cache → GEDMI03H; RC≠'0000' → 210, sev 2 (reject), reset sev 1 [L436-470]
  CONTR-220 : CIW+DA-CREA → GEDMI03H; RC≠'0000' → 220 (signal)                         [L473-502]
  CONTR-410 : READ NR-STNEW/NS-DBSTNEW ; '00' & (STCIRC '1' or ('9' & CT-SL '0')) → 410 (signal)
              '02' & STCIRC '9' & CT-SL ≠ '0' → 411 (signal)                           [L508-545]
  CONTR-411…: READ NR-ST-FORM-AS/NS-DB-STOCK ; '02' → 411 reject ;
              '00' & STATUS 'D' & STCIRC '1' → 413 reject                               [L550-600]
  RETKODE='00' (2nd READ) → CONTR-7XX:
              CPAID-in > NX-CPAID & STCIRC '9' → 712 (sev 1) ; CPAID-in < NX-CPAID → 711 reject ;
              CPAID-in + 1 < NX-CPCRE → 720 reject                                      [L606-636]
  HULP ≠ '2' → WRITE EFFECTEN, COUPONS, BOEKHOUD ; PROVISIE (NR-STNEW, NB-ST-USED 1)   [L373-383]
  READ next                                                                             [L387-388]
END   : VM9BD05T CLOSE (RC≠'0000' → USERABEN) ; CLOSE files ; STOP RUN                 [L312-328]
```

DB2 deviations from this flow: CONTR-110 not performed (D-02); OPEN/CLOSE calls and the `'CONSULTT'` move commented out (D-01, D-03). Everything else is a mechanical rename [OBS].

## 15. Rules and open questions

### 15.1 Rules reused

PLAT-01-c, CALL-01, CALL-02, CALL-03, CPY-01, NAME-03, ERR-04, RST-08, HLP-08, XPG-01, CMT-01, DATE-04, DATE-05 (PASS). Not applicable: RST-01..07/10, AUD-01/02, HLP-06 (caller), ORD-01, CNT-01, MSG-01, LRS-*/LRM-*.

### 15.2 New rules

| Rule | Statement | Guide |
|---|---|---|
| **CALL-N590-1** **NEW** | Interface fields set once before an OPEN call (`EF5-NM-FUNCTION`, `EF1-DA-PARM`, `EF1-INPUT`) are persistent inputs for every later call. Never drop them with a no-op OPEN/CLOSE; preferred: keep the OPEN/CLOSE calls unchanged (sister VMDZ1510/1573). | 01 |
| **CMT-N590-1** **NEW** | Diff gate: any statement live in legacy but commented in the target (`PERFORM`, `MOVE`, `CALL`) is a defect unless it is an IDMS verb/declarative removed by rule. In particular the PERFORM list of the main loop must be identical. | all |
| **LRO-N590-1** **NEW** | An LR path status `NO-<member>-FND` mapped via `SELECT COUNT(*)` must test the count (`= 0`), never `SQLCODE = 100` (COUNT always returns a row). | 04 |
