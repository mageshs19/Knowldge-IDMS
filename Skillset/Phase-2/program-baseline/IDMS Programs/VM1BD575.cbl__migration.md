## 2. Business flow

```
INITIALISATIE (L105-163)
  DATE-IND = '0' → ACCEPT DATE-YMD FROM DATE, window YY>60→19 else 20   [L107-115]
  else           → DATE-DMY8 ← DATE8-LS (PARM DDMMCCYY)                [L116-119]
  DATE-YMD8 ← DATE-DMY8                                                 [L121]
  OPEN, BIND, READY (all areas)                                         [L124-126]
  FFRECAB 'VM1BDF575-A' + DATE-YMD8 + NS-SET 0: OBTAIN CALC             [L133-137]
     found     → skip NS-REC-FF-IN records (VARYING TELLER, EOF-guarded) [L140-142]
     not found → STORE FFRECAB (SET '1', REC 'A', NB-DAY 7, counts 0)    [L144-151]
  TELLER ← 0 ; READ first ; VERWERKING until EOF ; CLOSE ; FINISH        [L154-163]
                                   ← NO final checkpoint (L-01)
VERWERKING (L166-184)
  STCIRC='1' → STORE-EVEF else MOD-EVEF
  ADD 1 TO TELLER ; TELLER>99 → NS-REC-FF-IN += TELLER, FIND CURRENT + MODIFY FFRECAB, COMMIT, TELLER 0
STORE-EVEF (L186-218)
  MOVE SPACES TO VMBEFF VMBEVEF ; EVEF ← DATE-YMD8, 0168, 0029, NR-ID-GOOD (HULP packed), DB-NR-CI ← NR-CIO-FORM-AS
  EFF key ← '1002' + NR-ST-FORM-AS + NS-DB-STOCK-FORM-AS
  STORE ST-VMBEVEF ; LR-ERROR or VMBEFF-NOT-FND → DISPLAY STOP01, LR-STATUS, CALL USERABEN
MOD-EVEF (L220-252)
  EFF key as above ; OBTAIN FIRST ALL-VMBEVEF-BY-VMBEFF AND TEVPR='0168' AND TGDSV='0029'
     not LR-FOUND → 'RECH EVTS ANNUL. SOUSCRIPTION' + NR-ST, NS-DB, LR-STATUS, USERABEN
  NR-ID-GOOD ← HULP (rebuilt) ; DB-NR-CI NOT touched ; MODIFY MO-VMBEVEF
     not LR-FOUND → 'UPDATE CLÉ FORM' + key + status, USERABEN
```

## 7. Cursor and transaction design

- **No cursors.** Two singleton SELECTs (11100 probe; 12100 with `FETCH FIRST ROW ONLY`), one INSERT, one UPDATE per record.
- **Commit:** every 100 input records (`WS-TELLER > 99`, seq 024500) and at EOF (F-PROG seq 038000). Checkpoint UPDATE + COMMIT in one paragraph (RST-LR-01). COMMIT SQLCODE checked (ERR-03, seq 048500-049100).
- **Restart table DZ01RSTV:** key `NM_ID_RS_PROGRAM='VMDZ1575'`, `NB_ID_RS_PHASE=1`, `DA_CR_RS=DA-DD-MM-CCYY` ('DD.MM.CCYY'); NB_DAY_RS 7; CO_ID_RS '0' running / '1' complete (seq 042000-042200, 045100-045300, 047300-047600).

## 12. Restart

| Aspect | Legacy | DB2 |
|---|---|---|
| Key | 'VM1BDF575-A' + DATE-YMD8 (system **or** PARM) + NS-SET 0 (L133-135) | 'VMDZ1575' / 1 / DA-DD-MM-CCYY (**always PARM**, D-01) |
